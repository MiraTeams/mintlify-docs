## MiraDay 是什么？
MiraDay 是面向专业与高管招聘的人才洞察平台。用日常语言描述一个岗位，Mira 就会返回一个合格候选人池，每位候选人都附带个人资料、匹配分析和联系方式。完整介绍见 [MiraDay 是什么](/zh/docs/meet-mira/what-is-mira)。

## 如何运行我的第一次搜索？
在新建频道界面描述岗位、粘贴或上传职位描述，或选择一个建议场景，然后发送。Mira 可能会先问几个澄清问题，随后在几分钟内返回一个经过排序的候选人池，你可以在同一个对话里持续优化。参见 [运行你的第一次搜索](/zh/docs/get-started/quick-start)。

## Mira 能作为一个团队处理大型搜索吗？
可以。每一次候选人搜索都由一支 [Agent Team](/zh/docs/meet-mira/agent-teams) 完成。Mira 把搜索交给负责寻访的 Teammate；工作量更大时，会再安排更多 Teammate，分别负责寻访、筛选、匹配等环节，在同一个频道里协作，你始终掌控全局。

## 候选人数据从哪来？
Mira 汇聚多个公开人才数据源的数据，并结合 Mira 自建的公开职业档案索引。你也可以上传自己的简历，并使用 [浏览器插件](/zh/docs/tools-and-teamwork/mira-browser-extension) 访问你已登录的网站，例如你的 ATS。详见 [MiraDay 是什么](/zh/docs/meet-mira/what-is-mira#候选人从哪里来)。

## 如何保存我找到的候选人？
把想在单个搜索之外保留的人选保存到 [联系人](/zh/docs/tools-and-teamwork/contacts)，这是工作区级别的名单。在某位候选人上点击 **添加至联系人**，或点 **导入** 把你自己的人选从 PDF、Word、Excel、CSV 或 HTML 文件导入。Mira 会持续补全并更新每位联系人的档案。

## 如何把候选人分享给团队或用人经理？
用 **获取邮箱** 和 **获取电话** 查看你需要的邮箱和电话，然后把候选人池下载为 Excel（.xlsx）文件，交给你的 ATS、表格或用人经理。查看联系方式会消耗积分。参见 [导出与分享](/zh/docs/get-started/export-and-share)。

## 什么是 Mira 浏览器插件，如何安装？
[Mira 浏览器插件](/zh/docs/tools-and-teamwork/mira-browser-extension) 让 Mira 在一个专用标签页里操作你自己的 Chrome 浏览器，使用你自己的登录状态。从 Chrome Web Store 安装并授权一次即可。可以用它读取 LinkedIn 等网站上最新的档案，让候选人数据保持最新；触达需要登录才能查看的候选人；在实时网络上调研公司；以及访问你已登录的其他工具，例如你的 ATS。

## 我可以保存反复使用的工作流吗？
可以。把反复使用的工作流、一种需求收集格式、一套评估标准或一种报告结构保存为一个 [技能](/zh/docs/tools-and-teamwork/skills)，然后在频道输入框输入 `/` 唤起它，而不用每次都描述同样的步骤。官方技能来自 Mira 团队；个人技能由你自己创建和分享。

## 可以连接我的邮箱吗？
可以。在 [连接器](/zh/docs/tools-and-teamwork/connectors) 里连上你的 Gmail 或 Outlook，Mira 就能在频道里起草、发送和总结邮件，你不用切回收件箱。

## 我上传的文件和报告在哪里？
[文件](/zh/docs/tools-and-teamwork/files) 把你所有频道里的内容集中到一个地方，包括你上传的简历和 JD，以及 Mira 生成的数据文件和报告，不再散落在一个个频道对话里。从侧边栏打开 **文件**。

## 如何获得访问权限，费用是多少？
MiraDay 已开放注册，无需邀请。访问 [mira.day](https://www.mira.day)，用 Google、Microsoft 继续，或用邮箱加密码注册，再输入验证码完成邮箱验证。套餐分为免费版（$0）、个人版（$199/月）、团队版（$399/席位/月）和企业版（定制）；每档套餐包含哪些内容，见 [积分](/zh/docs/account/credits)。

## 数据安全吗？
工作区文件、消息和私有笔记不在职业档案贡献范围内。你新增或更新的、符合条件的结构化职业字段，可能会贡献至 MiraDay 的共享索引用于招聘；具体边界及你的权利见[隐私政策](/zh/docs/match-quality-and-trust/privacy-policy)。
