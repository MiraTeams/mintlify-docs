MiraDay 是面向专业与高管招聘的人才洞察平台。其智能体 Mira 带着一支 Agent Team 为你找到对的候选人：描述一个岗位，Mira 就会搜索、推理，并把真正合适的人带回来。每一次搜索都有一支 Agent Team 投入工作，每名 Teammate 负责搜寻的一部分。繁重的工作量从你的案头卸下；而做决定的人，始终是你。


![MiraDay 工作区：描述一个岗位，查看由匹配到的候选人组成的候选人池](/docs/mira-overview.png)
