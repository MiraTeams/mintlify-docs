使用 Agent Team 时，Mira 担任团队负责人，安排多名 Teammate 分别负责任务的不同环节，而你始终掌控全局。候选人搜索是最常见的用法，但任何困难的多步骤工作都可以交给团队。

---

## 每个环节都有一名 Teammate

一个困难的工作有好几个环节。以一次搜索为例，常见做法是几名负责寻访的 Teammate 并行工作，各自负责一个地区或一类人才，另有 Teammate 调研公司或核查事实。其他多步骤工作也是如此，比如梳理一个市场，或同时分析多家公司。

每一次候选人搜索都由一支 Agent Team 完成：Mira 至少会把搜索交给一名负责寻访的 Teammate，工作需要时再安排更多。其他任务由 Mira 判断；聚焦、范围清晰的请求通常由 Mira 独立完成。

## 团队在频道里协同工作

频道是 Agent Team 工作的地方。就像一个真实的群聊团队一样，Teammate 会分享各自的发现、在彼此的工作基础上推进，并互相挑战对方的结论，得出更好的结果。你可以全程跟看，随时查看每一步的执行情况，并追溯每项结论背后的依据。

在右侧的**任务工作区**里，**任务计划**会随着各阶段完成持续更新，**成员实时状态**显示每名 Teammate 正在做什么。

团队完成后，Mira 会汇总所有 Teammate 的结果，并在主会话中向你交付最终答案。

## 团队里有谁

团队启动时，Mira 会列出这次召集了谁：“Mira 已组建 Agent Team，召集 N 名 teammates”，下面是每名 Teammate 的名字、角色和负责的工作。随后 Mira 会发出“Mira 邀请 … 加入频道”，并在**派单指令**里写明这次分给每名 Teammate 的具体工作。

Teammate 会独立完成自己那部分。涉及外部触达、敏感数据或高风险动作时，Mira 会先等你确认。

## 在搜索运行中调整方向

你确认的是方向，而不是事无巨细地操办。团队开始搜索之前，Mira 会请你查看并确认一份**理想人才画像**：你的必备条件、加分项和排除项。团队运行起来后，你在频道里和 Mira 说话就能调整方向，Mira 会把你的指引传给合适的 Teammate。你也可以在结果面板顶部的**理想人才画像**折叠条里修改画像，再点**开始搜寻**。如果当前搜索还在进行，Mira 会问你选择**等待**还是**发起新搜索**；选择发起新搜索会停止当前这轮。

## 启动团队

团队有两种启动方式：

1. **Mira 自动组建**：每一次候选人搜索都会组建，其他更适合用团队来做的任务也会。
2. **你手动开启**：点击频道输入框工具栏里的 **Agent Team** 按钮。激活时会高亮，并按频道记忆。开启后，Mira 在其他类型的工作中也会使用团队；候选人搜索无论开关与否都会使用团队。

## 积分

和 MiraDay 里的其他工作一样，一次 Agent Team 运行会消耗积分。你可以在**频道详情**的**消耗积分**里看到某个频道用了多少。

## 常见问题

### Agent Team 的 Teammate 能使用浏览器插件吗？

可以。如果工作需要，先授权浏览器控制，这是你在主对话里给出的一次性授权，之后 Teammate 也能浏览网页。Teammate 无法在运行途中请求这个授权，所以请提前开启。详见 [Mira 浏览器插件](/zh/docs/tools-and-teamwork/mira-browser-extension)。

### 可以不用 Agent Team 来搜索吗？

不可以。每一次候选人搜索都由一支 Agent Team 完成，哪怕只需要一名负责寻访的 Teammate。其他任务可以让 Agent Team 按钮保持关闭，由 Mira 判断；聚焦的请求通常由 Mira 独立完成。
