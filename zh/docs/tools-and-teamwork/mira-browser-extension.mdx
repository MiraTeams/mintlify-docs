Mira 浏览器扩展让 Mira 操作你自己的 Chrome 浏览器，获取内置来源里没有的信息，比如需要登录才能访问的网站。它使用你自己的登录状态，默认在专用标签页中工作，也可以使用你明确指定的已打开页面；你可以全程查看，也能随时接手。

---

## 可以用来做什么

- **浏览你指定的网站。** 把你想访问的具体网站告诉 Mira，Mira 会替你浏览，并把找到的内容带回来。
- **触达需要登录网页才能查阅的候选人。** 让 Mira 打开你已登录的招聘网站，Mira 会阅读候选人资料，把合适的人带回来做匹配。
- **调研公司和团队。** 问某家公司的管理层、最近的融资，或某个团队都有谁，Mira 会从实时网页里收集。
- **调用已通过网页登录的其他 SaaS 产品。** Mira 通过你自己的浏览器会话工作，因此能访问你已经登录的 ATS、CRM 或其他账号。

## 安装并连接

1. 在 [Chrome 网上应用店](https://chromewebstore.google.com/detail/mira-chrome-extension/eehnmnpglnfhkkcepfdlnnolobnjfcoh) 找到 **Mira 浏览器插件**，点击 **添加至 Chrome**。也可以在 **设置** 的 **浏览器插件** 里点 **安装扩展** 安装（仅桌面端）。
2. 频道输入框里有一个插件图标按钮（仅桌面端，手机端不显示）。检测插件期间按钮不可点击；未安装时点击会弹出安装引导；已安装但未连接时点击，会按情况显示 **连接**、**授权**、**更新** 或 **去升级**；连接后按钮变为开关（见下文）。
3. 首次需要用到浏览器时，Mira 会显示 **Mira 请求控制你的浏览器** 卡片。Mira 使用你已登录的网站，默认在频道专用标签页中操作；你也可以明确要求它在已有标签页中继续（见下文）。所有操作都有记录、可以查看，支付、删除等敏感操作会先请你确认。点击 **授权**，之后 Mira 会记住，不用每个频道都授权。

如果频道需要浏览时插件还没就绪，Mira 会弹出一张卡片，引导你完成安装、授权或重新连接，连接好之后，Mira 会自动继续执行任务。

如果你的插件版本低于 Mira 所需版本，浏览功能会被阻止，直到完成更新：Mira 会弹出一张**更新 Mira 浏览器插件**卡片（标有 **需要更新**），没有跳过选项。较新版本的插件可以直接点**立即更新**，一键完成更新，不用离开当前页面。否则，或者一键更新没有成功，就手动更新：

1. 在地址栏输入 `chrome://extensions/`，打开右上角的**开发者模式**，点左上角出现的**更新**。
2. 如果仍然无法更新，找到 Mira 插件点**移除**，再点卡片上的**去商店**，在商店页点**添加至 Chrome** 重新安装。

更新完成后，Mira 会自动继续执行任务。

## 在频道中使用

![插件在频道中工作：浏览器已连接状态卡片、Mira 的导航步骤，以及频道输入框中的插件按钮](/docs/channel-browser.png)

在频道里直接输入要完成的任务即可。Mira 会自己判断什么时候用浏览最合适，然后在你浏览器的一个专用标签页里工作。插件连接后，插件按钮同时是一个本轮可选的开关：不开，Mira 自己决定；打开，则本轮 Mira 优先用浏览器。

使用 **0.4.18 或更新版本**的扩展时，你可以让 Mira 在已打开的页面上继续。该标签页会成为当前任务的工作标签页，保留原有筛选条件和页面状态；如果不清楚你指的是哪个页面，Mira 会在对话中询问，不会额外显示授权卡片或浏览器弹窗。

如果 Mira 遇到需要你接管的环节，比如登录用户名及密码、验证码或二次验证，Mira 会**暂停并显示「继续」按钮**等你。你也可以随时自己接管标签页，Mira 会等着，你点 **继续** 后 Mira 恢复。你可以打开 **查看浏览器会话** 实时观看；支付、删除、发送这类敏感操作，Mira 每次都会先请你确认。

## 与你的团队协作

Agent Team 里的 Teammate 也能使用浏览器插件进行网页浏览。你只需在开始时一次性授权，Mira 为这个频道组建的 Teammate 就能以同样的方式，在你的浏览器里使用插件。

## 平台合规

很多招聘平台的服务条款会限制自动化访问。插件的设计遵循合理的使用方式，但遵守第三方平台条款的责任在你自己。建议把插件用于有针对性的具体搜索，而不是批量抓取，并让你自己的平台账号保持良好状态。

## 隐私与安全

- Mira 使用你自己的浏览器和登录状态，默认在频道专用标签页中操作。你明确指定已有页面后，该标签页会成为任务的工作标签页；其他无关标签页不在任务范围内。
- Mira 不会存储你的密码或 cookie，而是使用你已经登录的会话。
- 敏感操作会先请你确认，每一步操作都会被记录、可随时查看。
- 插件目前仅支持 Chrome 浏览器。
- 所有数据处理都遵循 MiraDay 的[隐私政策](/zh/docs/match-quality-and-trust/privacy-policy)。
