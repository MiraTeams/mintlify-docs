连接器把你自己的账户接入 MiraDay，让 Mira 在频道里工作时可以直接调用。招聘顾问最先用到的通常是邮箱：连上你的 **Gmail** 或 **Outlook**，Mira 就能在频道里起草、发送和总结邮件，你不用在 Mira 和收件箱之间来回切换。

---

## 连接你的邮箱

![频道输入框里的连接器入口，带待连接的 Gmail 和 Outlook，以及管理连接器的链接](/docs/connectors-email.png)

1. 从 **设置** 打开 **连接器**，或从频道输入框的连接器入口打开。
2. 找到 **Gmail** 或 **Outlook**，点 **连接**。
3. 按提示 **授权** Mira。Mira 会把你带去登录并授予访问权限，然后返回。
4. 连接完成后，这个邮箱就能在任何频道里使用了。

已连接的服务排在列表最前面。点击某个连接器进入详情页，可以逐个开启或关闭工具；标有 **需确认** 的工具只有你确认后才会执行。你可以随时 **断开连接**（Mira 会先请你确认），访问权限会立即撤销，之后也能重新连接。

## Mira 能对你的邮件做什么

邮箱连接好之后，就可以在频道里让 Mira 直接处理邮件：

- **起草。** Mira 会在内置的 **Email 画布** 里起草邮件，**收件人**、**抄送**、**密送**、**主题** 和 **邮件正文** 都能直接修改，还能添加附件。发出去之前，你可以先看一遍、按需调整。
- **发送。** 草稿写好后，点 **发送**。在邮件真正发出去之前，Mira 会再让你确认一次，你不点确认就不会发出。
- **转发。** 在频道里直接转发邮件。原邮件的附件会一并带上；转发邮件不支持新增附件。
- **读取和总结。** 让 Mira 处理你的收件箱，帮你把一长串邮件读完、给出要点，或者快速了解新来的邮件，全程不用离开频道。

## 隐私与安全

- 连接器使用你自己的授权。Mira 只会用已连接的账户，去做你在频道里明确要求的事。
- 未经你确认不会发出任何邮件；你也可以随时在连接器页面断开任意连接器，访问权限会立即撤销。
- 所有数据处理都遵循 MiraDay 的[隐私政策](/zh/docs/match-quality-and-trust/privacy-policy)。
