這篇指南帶你走完第一個人才搜尋任務：從描述職位到檢視一份合格的候選人池。

<Steps>

<Step title="描述職位">

登入後，你會看到新建頻道介面，帶一個文字輸入框與幾個推薦場景。

![MiraDay 新建頻道介面：描述你的需求，Mira 接手處理](/docs/task-new.png)

你有兩種方式：

- **自己寫描述**：貼上或上傳一份 JD，或用你自己的話描述職位。想寫得多具體都可以。例如：

  > 我在找一位資深全端工程師，有 React 和 Node.js 經驗，最好來自高成長新創公司。工作地點：柏林或遠端。

- **選推薦場景**：點擊輸入框下方的範例 prompt，快速開始。

然後點擊輸入框右側的傳送按鈕。

<Note>
不需要正式的 JD。你可以像跟同事交代需求那樣描述職位；Mira 理解自然語言，包括「高成長公司背景」或「曾從零打造過團隊」這類隱含條件。
</Note>
</Step>

<Step title="確認細節（僅在需要時）">

Mira 會分析你的輸入，判斷資訊是否足以開始搜尋。如果你的描述已經夠具體，Mira 會直接進行搜尋，不顯示表單。如果關鍵細節缺失或模糊，Mira 會顯示一份簡短的澄清表單。它的問題會依你的任務客製，聚焦在會影響搜尋的選擇，例如：

- **要著重的關鍵職責**：職位中哪些部分對找到合適的人最重要。
- **範圍或地點覆蓋**：搜尋應涵蓋的地區或工作地點。
- **公司類型偏好**：新創、高成長公司，或某種特定類型的組織。

確切的問題因任務而異。Mira 會預選合理的預設值，你可以檢視、視需要調整，然後點擊 **提交**，或點擊 **跳過（使用預設值）** 直接採用 Mira 的建議。Mira 會根據你的答案起草一份[理想人才畫像](/zh-TW/docs/meet-mira/how-mira-works)，下一步由你確認。

<Note>
表單只在能提升結果時才出現。前期描述越充分，後面被打斷的次數就越少。
</Note>
</Step>

<Step title="確認理想人才畫像">

Mira 會把你的需求整理成一份 **理想人才畫像**：必備條件、加分條件與排除條件。檢查一遍，點擊 **編輯** 修改任一列，然後點擊 **開始搜尋**。Mira 只有在你確認之後才會開始尋訪。
</Step>

<Step title="檢視你的候選人池">

Mira 會在各個人才資料來源中搜尋，回傳你的候選人池。

![MiraDay 候選人池：候選人帶匹配分析與聯絡方式](/docs/task-shortlist-en.png)

你會看到：

- **右側面板的候選人卡片**，每張顯示：
  - 姓名，以及候選人在本次搜尋所用平台上的個人檔案連結，例如 LinkedIn、GitHub 或 Hugging Face。
  - 目前職稱、公司與任職時間。
  - 地點與最高學歷。
  - 一份 **匹配分析**，逐條對照你的必要條件評估候選人，並附匹配標籤：**高度匹配**（綠色）、**部分匹配**（黃色）或**匹配度低**（灰色）。
  - 電子郵件與電話，預設隱藏。點擊 **取得信箱** 或 **取得電話** 即可按需查看，這會消耗積分。

- **一份可下載的資料檔案**，包含每位候選人的細節。批次揭露聯絡方式、下載檔案與分享，請見[匯出與分享](/zh-TW/docs/get-started/export-and-share)。

點擊卡片即可開啟候選人的完整檔案，或點擊姓名旁的 LinkedIn 圖示前往 LinkedIn。
</Step>

<Step title="精煉或繼續">

檢視完候選人池後，在同一個頻道中繼續與 Mira 對話：要求更多候選人，或調整條件（「也包含阿姆斯特丹的候選人」）。你也可以展開結果面板頂端的 **理想人才畫像** 列，編輯後點擊 **開始搜尋**。要換一個職位，點擊側邊欄的 **新建頻道**。更多做法請見[優化你的搜尋](/zh-TW/docs/sourcing/refine-and-export)。

每個頻道都會儲存在側邊欄，你隨時可以回到任意一次搜尋。每個頻道旁邊都有一個標記，顯示它目前的狀態：任務執行中時是一個呼吸閃爍的圓點，等待你確認時是一個手形圖示，任務已完成但你還沒開啟時則是一個藍色圓點。
</Step>

</Steps>
