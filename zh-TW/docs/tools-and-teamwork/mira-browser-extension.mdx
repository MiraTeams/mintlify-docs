Mira 瀏覽器擴充功能讓 Mira 操作你自己的 Chrome 瀏覽器，觸及那些不在其內建資料來源中的資訊，例如需要登入的網站。它使用你自己的登入帳號，預設在專屬分頁中運作，也可以使用你明確指定的已開啟網頁。你可以隨時查看它在做什麼，並在任何時候介入。

---

## 你可以用它做什麼

- **瀏覽你指定的網站。** 給 Mira 一個你想造訪的特定網站，Mira 會替你瀏覽，然後帶回找到的內容。
- **觸及需要登入才能查看的候選人。** 開啟一個你已登入的招聘網站，Mira 會閱讀個人檔案，然後帶回合格的候選人進行匹配。
- **調研公司與團隊。** 詢問某家公司的領導層、近期融資，或某個特定團隊有哪些成員，Mira 會從即時網路上蒐集這些資訊。
- **觸及你已登入的其他 SaaS 工具。** Mira 透過你自己的瀏覽器工作階段運作，因此能觸及你的 ATS、CRM，或其他你已經登入的帳號。

## 安裝與連接

1. 在 [Chrome Web Store](https://chromewebstore.google.com/detail/mira-chrome-extension/eehnmnpglnfhkkcepfdlnnolobnjfcoh) 上找到 **Mira 瀏覽器擴充功能**，點擊 **Add to Chrome**。你也可以在 **設定** 的 **瀏覽器外掛** 中，使用 **安裝擴充功能** 按鈕安裝（僅限桌面版）。
2. 頻道輸入框中會出現一個小型擴充功能圖示（僅限桌面版，行動裝置上不會顯示）。Mira 偵測擴充功能期間，按鈕無法點擊。若尚未安裝擴充功能，點擊後會開啟安裝步驟；若已安裝但尚未連接，點擊後會依實際需要提供 **連接**、**授權**、**更新** 或 **前往升級**；連接完成後，按鈕就成為一個開關（見下方說明）。
3. Mira 第一次需要使用你的瀏覽器時，會顯示一張 **Mira 請求控制你的瀏覽器** 卡片。Mira 會使用你已登入的網站，預設在該頻道的專屬分頁中操作；你也可以明確要求它接續現有分頁操作（見下方）。所有操作都會被記錄並可供查看，付款或刪除等敏感操作會先詢問你。點擊 **授權**，之後就會被記住，因此每個頻道都不需要再另行設定。

如果某個頻道需要擴充功能時它尚未就緒，Mira 會顯示一張卡片，引導你完成安裝、授權或重新連接，一旦你連接好，Mira 會自行接續原本的頻道。

如果你的擴充功能版本低於 Mira 要求的版本，瀏覽功能會在你更新之前被封鎖：Mira 會顯示一張**更新 Mira 瀏覽器擴充功能**卡片，標有**需要更新**，沒有略過的選項。在較新版本的擴充功能上，點擊 **立即更新**，就能一鍵完成更新，不必離開頁面。否則，或一鍵更新沒有成功時，請手動更新：

1. 前往 `chrome://extensions/`，開啟右上角的 **開發人員模式**，再點擊左上角的 **更新**。
2. 如果仍然無法更新，找到 Mira 擴充功能並點擊 **移除**，然後使用卡片上的 **前往商店** 按鈕，點擊 **加到 Chrome** 重新安裝。

更新完成後，Mira 會自動接續原本的頻道。

## 在頻道中使用它

![擴充功能在頻道中運作：瀏覽器已連接狀態卡片、Mira 的導覽步驟，以及頻道輸入框中的擴充功能按鈕](/docs/channel-browser.png)

只要在你的頻道中輸入你需要完成的事情即可。Mira 會自行判斷何時瀏覽是取得所需資訊的最佳方式，然後在你自己瀏覽器的專屬分頁中進行。當擴充功能已連接時，它的按鈕也可作為當前這一輪的選用開關：不開啟它，就由 Mira 自行判斷；開啟它，則讓 Mira 這一次優先使用瀏覽器。

使用 **0.4.18 或更新版本**的擴充功能時，你可以讓 Mira 接續已開啟的網頁操作。該分頁會成為任務的工作分頁，保留目前的篩選條件與頁面狀態；如果不確定你指哪個網頁，Mira 會在對話中詢問，不會再顯示額外的授權卡片或瀏覽器對話框。

如果 Mira 遇到需要你處理的步驟，例如以帳號和密碼登入、CAPTCHA，或雙重驗證提示，Mira 會**暫停並顯示一個繼續按鈕**然後等待。你也可以在任何時候自行接管該分頁；Mira 會等待，並在你點擊 **繼續** 時恢復。你可以開啟 **查看瀏覽器工作階段** 來即時觀看，而敏感操作，例如付款、刪除或送出某項內容，一律會先請你確認。

## 與你的團隊協作

Agent Team 中的 Teammate 也能使用這個擴充功能來瀏覽。你只需在一開始授予一次瀏覽器存取權，Mira 為該頻道啟動的 Teammate 就能以同樣的方式，在你的瀏覽器中使用這個擴充功能。

## 平台合規

許多招聘平台的服務條款限制自動化存取。這個擴充功能的設計是在合理的使用模式下運作，但遵守第三方平台條款的責任在於你。我們建議將它用於有針對性的特定搜尋，而非批量抓取，並保持你自己的平台帳號良好狀態。

## 隱私與安全

- Mira 使用你自己的瀏覽器與登入帳號，預設在該頻道的專屬分頁中運作。若你明確指定已開啟的網頁，該分頁就會成為任務的工作分頁；無關分頁不在任務範圍內。
- Mira 不會儲存你的密碼或 cookie；它透過你已經登入的工作階段運作。
- 敏感操作一律會先請你確認，且每個操作都會被記錄下來並可供查看。
- 這個擴充功能目前僅支援 Chrome。
- 所有資料處理皆遵循 MiraDay 的[隱私政策](/zh-TW/docs/match-quality-and-trust/privacy-policy)。
