## MiraDay 是什麼？
MiraDay 是一個面向專業與領導層招聘的人才洞察平台。用白話描述一個職位，Mira 就會回傳一份合格候選人的候選人池，每位候選人都附個人資料、匹配分析與聯絡方式。完整介紹見 [MiraDay 是什麼](/zh-TW/docs/meet-mira/what-is-mira)。

## 我要怎麼執行第一次搜尋？
在新建頻道介面描述職位、貼上或上傳一份 JD，或選擇一個推薦場景，然後送出。Mira 可能會先問幾個澄清問題，接著在幾分鐘內回傳一份排序後的候選人池，你可以在同一段對話中持續精煉。詳見 [執行你的第一次搜尋](/zh-TW/docs/get-started/quick-start)。

## Mira 能組成團隊處理大型搜尋嗎？
可以。每一次候選人搜尋都以 [Agent Team](/zh-TW/docs/meet-mira/agent-teams) 執行。Mira 會把搜尋交給一名負責尋訪的 Teammate；遇到規模較大的工作，則會再找來更多 Teammate，各自負責尋訪、篩選、匹配等不同環節。他們在同一個頻道中協作，而你全程保持掌控。

## 候選人資料從哪裡來？
Mira 匯集多個公開人才資料來源，再加上自建的公開專業檔案索引。你也可以上傳自己的履歷，並使用 [瀏覽器擴充功能](/zh-TW/docs/tools-and-teamwork/mira-browser-extension) 存取你已登入的網站，例如你的 ATS。詳見 [MiraDay 是什麼](/zh-TW/docs/meet-mira/what-is-mira#候選人從哪裡來)。

## 找到的候選人要怎麼保存？
想把某個人留在單一搜尋之外，就把他保存到 [聯絡人](/zh-TW/docs/tools-and-teamwork/contacts)，也就是你工作區層級的清單。在候選人上點擊 **新增至聯絡人**，或從 PDF、Word、Excel、CSV 或 HTML 檔案 **匯入** 你自己的人脈。Mira 會持續補全每位聯絡人的檔案，讓資訊保持最新。

## 要怎麼把候選人分享給團隊或用人主管？
用 **取得信箱** 和 **取得電話** 揭露你需要的電子郵件與電話，然後把候選人池下載成 Excel（.xlsx）檔案，交付給你的 ATS、試算表或用人主管。揭露聯絡方式會消耗積分。詳見 [匯出與分享](/zh-TW/docs/get-started/export-and-share)。

## 什麼是 Mira 瀏覽器擴充功能？要怎麼安裝？
[Mira 瀏覽器擴充功能](/zh-TW/docs/tools-and-teamwork/mira-browser-extension) 讓 Mira 在專屬分頁中用你自己的登入帳號操作你的 Chrome 瀏覽器。從 Chrome Web Store 安裝並授權一次即可。用它從 LinkedIn 等網站讀取最新的檔案，讓候選人資料保持即時；觸及需要登入才能查看的候選人；在即時網路上研究公司；並存取你已登入的其他工具，例如你的 ATS。

## 我可以把反覆使用的工作流程存起來嗎？
可以。把反覆使用的工作流程（需求釐清格式、評估準則、報告架構）存成一個 [Skill](/zh-TW/docs/tools-and-teamwork/skills)，之後在頻道輸入框輸入 `/` 叫出它，不必每次重新描述同樣的步驟。官方 Skills 由 Mira 團隊提供；個人 Skills 由你自己建立與分享。

## 我可以連接我的電子郵件嗎？
可以。從 [Connectors](/zh-TW/docs/tools-and-teamwork/connectors) 連接你的 Gmail 或 Outlook，Mira 就能在頻道中直接幫你起草、傳送和摘要郵件，不必再切回收件匣。

## 我上傳的檔案和報告在哪裡？
[Files](/zh-TW/docs/tools-and-teamwork/files) 把你所有頻道的東西集中到一處：你上傳的履歷和 JD，加上 Mira 生成的資料檔案和報告，不再散落在各個頻道對話串中。從側邊欄開啟 **Files**。

## 要怎麼取得使用權？費用如何？
MiraDay 已開放註冊，無需邀請碼。前往 [mira.day](https://www.mira.day)，使用 Google 或 Microsoft 繼續，或用電子郵件加密碼註冊，再輸入我們寄給你的驗證碼完成電子郵件驗證。方案有免費版（$0）、個人版（$199/月）、團隊版（$399/席位/月）與企業版（客製）；各方案內容見 [Credits](/zh-TW/docs/account/credits)。

## 我的資料安全嗎？
工作區中的檔案、訊息與私人筆記不在專業檔案欄位的貢獻範圍內。你新增或更新、符合條件的結構化專業欄位，可能會貢獻至 MiraDay 的共享索引，用於招募；相關界線與你的權利請見[隱私政策](/zh-TW/docs/match-quality-and-trust/privacy-policy)。
