MiraDay 是一個面向專業與領導層招聘的人才洞察平台。其智能體 Mira 會率領一支 AI 團隊，為你找到對的候選人：描述一個職位，Mira 就會搜尋、推理，把真正合適的人帶回來。每一次搜尋都有一支 Agent Team 上陣，每名 Teammate 各自負責尋訪的一環。繁重的工作量從你桌上卸下，而拍板的人始終是你。


![MiraDay 工作區：描述一個職位，並查看由匹配到的候選人組成的候選人池。](/docs/mira-overview.png)
