你候選人池中的每位候選人，都附有為你的搜尋量身打造的檔案。Mira 會把在多個公開來源找到的同一個人合併成一位候選人，檔案也會隨著從這些來源蒐集到更多資訊而持續補全。私有聯絡人紀錄與公開來源的候選人會保持獨立，即使是同一個人也不會合併。以下說明如何解讀它並判斷匹配度。

## 候選人卡片上的內容

![候選人檔案，包含姓名、地點、目前職位、學歷，以及帶有高度匹配標籤的匹配分析](/docs/candidates-mira-scores-each.png)

在結果面板中，每位候選人以一張卡片呈現，內容包括：

- **頂部**：姓名，以及可點擊的來源連結，連往此人在本次搜尋所用資料來源上的個人檔案，例如 LinkedIn、GitHub、Hugging Face、X (Twitter)，還有發現他的招聘平台。只要請 Mira 到 GitHub 或 Hugging Face 等資料來源搜尋，卡片上就會出現對應的個人檔案連結。
- **目前職位**（頭銜 · 公司 · 起止日期），下一行是 **地點 · 最高學歷**（學位、院校、專業與年份）。
- **匹配分析**預覽，附帶整體匹配標籤，先顯示前 5 項要求，點擊 **展開更多** 即可展開其餘內容。

點擊卡片即可開啟完整檔案（**詳情**）。完整檔案會再加入信箱與電話兩列、一段**自我介紹**摘要、逐項要求的完整評估、完整的工作經歷與教育背景、技能與語言能力、GitHub 與 Hugging Face 上的活動，以及在有資料時顯示的論文、榮譽獎項、證書與課程，還有一個**更多**區塊，列出網路與新聞中的提及（文章標題、發布日期與一句相關內容）。使用頂部的箭頭即可切換到上一位或下一位候選人。

結果面板預設為**卡片檢視**。使用面板頂部的切換鈕改成**清單檢視**，就能看到一張精簡的表格（候選人與匹配標籤、連結、信箱、電話、所在地、目前職位、目前公司、學校名稱、學歷、專業），方便一次快速掃讀大量候選人。

## 匹配標籤

每位候選人都帶有一個顏色標籤，總結其與你搜尋的匹配程度：

- **高度匹配**（綠色）：與你要求最契合的候選人。
- **部分匹配**（黃色）：部分符合、值得一看的候選人。
- **匹配度低**（灰色）：距離最遠、與你要求契合度最弱的候選人。

候選人依匹配度排序，因此最契合的排在最上方。

## 匹配分析

**匹配分析**會逐項列出你的必備條件。針對每一項，Mira 會標明候選人符合（勾號）、證據不足（橫線）或未達標（叉號），並附上每項判斷背後的依據。匹配分析是針對你這次特定搜尋撰寫的，而非通用簡介。

## 如何評估候選人

標籤與匹配分析能讓你快速掌握概況。在做決定前，請再深入了解：

- **不要只看頭銜。** 同樣的頭銜在不同公司意味著不同的意義。10 人新創公司的「高級工程師」與大公司同一頭銜是非常不同的角色。運用公司背景來理解真實的職責範圍。
- **檢視職業軌跡。** 晉升速度與跨職位的公司類型能透露許多資訊。一個從大企業跳到新創公司、再到成長期公司的人，與一直待在同一環境的人有著不同的畫像。
- **把匹配分析當作起點。** 匹配分析會突顯與你搜尋最相關的部分。想了解它無法涵蓋的細節，請閱讀完整的工作經歷與教育背景。

## 聯絡候選人

每張卡片都有信箱與電話兩列。在卡片上、清單檢視中或完整檔案裡，點擊**取得信箱**或**取得電話**即可取得聯絡方式。電話查詢進行中時，該列會顯示**取得電話中…**。若要一次取得多位，將滑鼠移到卡片頭像上勾選核取方塊（或使用**全選**），再點擊面板底部工具列的**取得信箱**或**取得手機號**，每次最多 50 人。取得聯絡方式會消耗積分，電話的消耗比電子郵件更高。

你自己的聯絡人庫中已有的電子郵件與電話可直接顯示。在完整檔案中，**補全郵箱**與**補全電話**可再次查詢，並合併新增的資料；查詢可能消耗 Credits，需等候一段時間才能再次嘗試，也不保證每次都能找到新資料。

## 保存一位候選人

若想把某個人留到這次搜尋之外，就點擊其卡片右上角的 **新增至聯絡人** 圖示（或完整檔案中的按鈕）。若要一次保存多位，勾選他們的核取方塊，再點擊底部工具列的 **新增至聯絡人**。他們會被加入 [聯絡人](/zh-TW/docs/tools-and-teamwork/contacts)，也就是你工作區層級的清單，在那裡你可以補全資訊並讓他們保持最新。

結果面板較窄時，**取得手機號**與**新增至聯絡人**可能收在底部工具列的**更多**中。**批次下載**仍會顯示。
