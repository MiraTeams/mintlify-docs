有了 Agent Team，Mira 會擔任團隊負責人，帶進多名 Teammate 各自負責任務的不同部分，而你始終保持掌控。招聘搜尋是最常見的用途，但團隊也能承接任何困難的多步驟工作。

---

## 每個環節都有一名 Teammate

困難的工作包含多個環節。以一次搜尋為例，常見的做法是幾名負責尋訪的 Teammate 平行作業，各自負責一個地區或一類人才，另有 Teammate 調研公司或查證事實。其他多步驟工作也是如此，例如繪製市場地圖，或同時分析多家公司的概況。

每一次候選人搜尋都以 Agent Team 執行：Mira 一定會把搜尋交給至少一名負責尋訪的 Teammate，工作需要時再找來更多。其他任務由 Mira 判斷；目標明確、範圍聚焦的請求，通常由 Mira 獨立完成。

## 團隊在頻道中協作

頻道是 Agent Team 工作的地方。就像真正的團隊在群組聊天裡協作一樣，Teammate 會分享彼此的發現、在對方的成果上持續推進，並互相挑戰彼此的結論以得出更好的結果。你可以從頭到尾跟著看，即時查看任何一個步驟，並追溯每個結論背後的依據。

在右側的 **任務工作區** 中，**任務計畫** 會隨各階段完成而更新，**成員即時狀態** 則即時顯示每名 Teammate 正在做什麼。

團隊完成後，Mira 會把每名 Teammate 的成果彙整起來，在主對話中把最終答案交付給你。

## 團隊裡有誰

團隊啟動時，Mira 會列出這次召集了誰：「Mira 已組建 Agent Team，召集 N 名 teammates」，接著是每名 Teammate 的名稱、角色與負責的工作。隨後 Mira 會發出「Mira 邀請 … 加入頻道」，並列出每名 Teammate 的 **派單指令**，也就是這次執行分配給他們的具體工作。

Teammate 會各自獨立完成自己負責的部分。當某個步驟涉及對外觸達、敏感資料或高風險操作時，Mira 會先等你確認。

## 在搜尋執行時加以引導

你確認方向，而不是事必躬親地管理每項工作。團隊開始搜尋之前，Mira 會請你檢視並確認一份 **理想人才畫像**：你的必備條件、加分條件與排除條件。團隊一旦開始運作，你就透過在頻道中與 Mira 交談來引導，Mira 會把你的指示傳達給合適的 Teammate。你也可以在結果面板頂端的 **理想人才畫像** 列中編輯畫像，再點擊 **開始搜尋**。如果搜尋仍在進行，Mira 會詢問你要選擇 **等待** 還是 **發起新搜尋**；選擇後者會停止目前的搜尋。

## 啟動團隊

團隊有兩種啟動方式：

1. **Mira 自動組建**：每一次候選人搜尋都會自動組建，其他更適合由團隊處理的任務也是如此。
2. **你手動開啟**：點擊頻道輸入工具列中的 **Agent Team** 按鈕。啟用時按鈕會高亮顯示，且此設定按頻道記憶。開啟後，Mira 在其他類型的工作中也會使用團隊；候選人搜尋則無論開關與否都會使用團隊。

## 積分

與 MiraDay 的其他工作一樣，Agent Team 的執行會消耗積分。你可以在 **頻道詳情** 的 **消耗積分** 中查看某個頻道用了多少。

## FAQ

### Teammate 可以使用瀏覽器擴充功能嗎？

可以。如果工作需要，請先授權瀏覽器控制，這是你在主對話中給予的一次性核准，之後 Teammate 也能瀏覽網頁。Teammate 無法在執行過程中要求這項授權，所以請事先開啟。詳見[瀏覽器擴充功能](/zh-TW/docs/tools-and-teamwork/mira-browser-extension)。

### 可以不透過 Agent Team 執行搜尋嗎？

不行。每一次候選人搜尋都以 Agent Team 執行，即使只需要一名負責尋訪的 Teammate。其他任務則可讓 Agent Team 按鈕保持關閉，由 Mira 判斷；目標聚焦的請求通常由 Mira 獨立完成。
