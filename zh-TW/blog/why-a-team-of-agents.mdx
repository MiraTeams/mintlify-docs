打造 MiraDay 的過程中，我們反覆思考，也和許多優秀的招聘顧問深入討論：好的招聘，到底是怎麼發生的。

招聘顧問接下一個棘手的職位時，工作通常從需求梳理開始。光有 JD 通常遠遠不夠，還得搞清楚：公司為什麼要招這個人、團隊想達成什麼目標、用人主管寫下的那些要求到底是什麼意思、這份需求裡哪些是必要的、哪些其實可以商量、招聘成功的標準是什麼、以及尋訪策略該怎麼定。

到這時，人才尋訪才真正開始。而在尋訪的過程中，方向和策略會不斷校準、不斷調整，有時甚至會改變你對這個職位最初的理解。

在尋訪的一開始，你心裡可能已經有一個非常具體的理想人選樣貌。在市場裡搜尋一段時間後，你可能會發現，最合適的候選人和當初想像的相差很大；又或者你會發現，某條你以為必不可少的要求，正把搜尋範圍收得太窄。這種情況在稀缺的技術職位和高階管理職位搜尋中尤其常見。

於是你擴大搜尋範圍，並開始更仔細地研究找到的每一位候選人。有些履歷看起來很有希望的人，一旦細看實際經歷，才發現方向不對；而有些履歷看起來平淡無奇的人，反而比預期更合適。這些新發現，又會再次改變搜尋方向。

這就是優秀招聘顧問真正的工作方式。整個過程並不是從需求梳理到尋訪、再到評估的一條直線，而是某個階段的發現會改變你處理下一個階段的方式，有時甚至會把你送回起點，重新梳理需求。

## AI 招聘往往從另一個假設出發

目前市面上大多數 AI 招聘產品的做法，是把整套流程交給一個 Agent。你描述一個職位，Agent 負責理解需求、搜尋候選人、評估找到的結果，再給你一份候選人名單。

但這個做法有一個問題，而且搜尋難度越高，這個問題就越明顯。

那個負責解讀職位、決定搜尋策略與方向的 Agent，同時也是執行搜尋的那一個；接著，它又拿自己一開始做出的假設，去評估找到的候選人。如果最初的理解有一點點偏差，接下來的整個流程，就會非常有效率地朝錯誤的方向一路走下去。

招聘顧問通常有辦法察覺這一點。市場本身會反過來挑戰最初的需求，同事和用人主管會質疑搜尋策略，仔細讀一份候選人的履歷，也可能發現某條要求其實不太對。這些不斷出現的訊號，能幫助招聘顧問及時調整、溝通與校準，最終找到合適的人選。

當所有這些工作都在單一 Agent 裡完成時，這些「摩擦」的時刻很容易就消失了。而我們認為，正是這種摩擦，才真正幫助你找到合適的人。

## 我們研究了招聘團隊原本是怎麼合作的

Agent Team 的想法，正是從這裡來的。

我們一開始問的不是「怎麼讓一個 Agent 做更多事」。

我們真正問的是：如果組一支招聘團隊來交付一個棘手的職位，我們會希望這支團隊怎麼運作？

答案其實相當熟悉：把工作合理分工。有人在搜尋走得太遠之前，先真正弄懂這個職位；有人深入市場，看看那裡到底有些什麼人；還要有人仔細研究候選人，而不是想當然地把「好的搜尋結果」當成「好的候選人」。

關鍵在於，每位成員都有各自專注的部分，並用不同方式互相協作，而不是各自孤立地工作。負責尋訪的人可能會回頭說：「我沒找到我們預期的那種人，也許我們該重新想想這條要求。」負責評估候選人的人，可能會注意到某種模式，進而改變整個團隊該尋找的方向。招聘就是這樣一步一步變好的。

所以在 MiraDay，我們圍繞這些不同的工作環節打造各個 Agent，並讓它們作為隊友緊密連結在一起。

## Mira、Atlas、Scout 與 Vera

**Mira** 是整個 Agent Team 的「大腦」。它主導整個任務，決定怎麼拆解和規劃工作，並判斷什麼時候一場搜尋需要不只一種思考方式。

**Atlas** 負責需求梳理。它研究公司、市場、競爭對手與薪酬水準，再把最初的需求轉化成一份職位研究（Role Brief）：這個職位真正需要什麼，包括業務背景、成功標準、限制條件、假設，以及這次招聘背後尚待釐清的問題。再由這份職位研究推導出一份理想人才畫像（Ideal Candidate Profile）：也就是這次搜尋會依循的具體必要條件、加分條件與排除條件。這麼做的目的，不是產出一份更精緻的 JD，而是把招聘背後的那些假設攤得夠清楚，清楚到真的能被檢驗。

**Scout** 把這份理解帶進市場。它跨多個資料來源搜尋，找出可能符合理想人才畫像的人，並彙整成一個候選人池。它找到的事實，也可能反過來挑戰這份理想人才畫像，有時甚至挑戰它背後的職位研究。

如果最強的候選人一再來自某個意想不到的地方，這本身就是有用的資訊。答案不一定是更努力地繼續搜尋；有時候，正確的做法是退一步，重新考慮這個職位。

這個候選人池還不是短名單（shortlist）。由人來決定誰能進入初步候選名單（longlist），**Vera** 從這裡接手：持續深入研究這些候選人，建立足以支撐決策的證據，準備個人化的接觸內容，並協助初步聯繫與篩選。

Vera 的發現，同樣會回饋到搜尋當中。這是刻意的設計。

這些隊友並不是要按一個固定順序前進、把結果交給下一位。它們要在搜尋推進的過程中，彼此影響。

## 重點不在於 Agent 的數量

我們並不認為三個 Agent 天生就比一個 Agent 好。

真正有意思的是，當招聘流程裡不同的環節被允許互相質疑時，會發生什麼事。

市場向你展示的東西，會重塑這份理想人才畫像；你從某一位候選人身上學到的東西，會改變整場搜尋；而更仔細地審視一個人，可能會改變你對「合適的候選人該是什麼樣子」的整體判斷。

這也是為什麼我們把所有工作都放在同一個頻道裡，讓你看得見。你能看到團隊正在找到什麼、它的想法在哪裡發生轉變，而不是從一個黑箱裡收到一份最終名單。

這麼做的目的，不是讓流程看起來更複雜，而是讓搜尋背後的推理更公平、更透明：讓你能信任、能查核、能追溯。

## 團隊負責找，你負責定

Agent Team 能承擔搜尋裡許多耗時的工作。它可以研究職位、摸清市場、調查候選人，並整理好證據，但它不做最終的錄用決定。

決策權，始終留在招聘顧問手上。

我們認為這個區分很重要，因為「找到資訊」和「判斷這些資訊代表什麼」，根本是兩件不同的事。AI 能幫你看到一個遠比你單打獨鬥時更大的市場，也能讓你把更多時間，留給招聘裡真正需要經驗與判斷力的那些部分。

這也是我們對 MiraDay 定位的理解：始終圍繞著那些能幫助招聘顧問做出更好判斷的任務。

## Mira 什麼時候會找來整支團隊

大多數搜尋並不需要一整支團隊。

直接了當的搜尋，Mira 自己就能處理。當一場搜尋複雜到需要從不同角度檢驗其中的假設時，Mira 就會找來 Agent Team。

我們還在摸索 Agent Team 該在什麼時候介入、成員之間該如何協作。隨著我們看到更多真實的搜尋案例、更清楚招聘顧問實際會卡在哪裡，這支團隊也會持續調整。

這一切探索背後的想法其實很簡單。我們不希望一個 Agent 變成「什麼都自己扛的招聘顧問」的越來越龐大的放大版。我們希望 Mira 更像一支優秀的招聘團隊那樣工作：先弄懂職位，再從市場裡學習，仔細審視你找到的人，並讓學到的東西，改變你接下來要做的事。

因為找到對的人，從來就不是一條直線。

**團隊負責找，你負責定。**
