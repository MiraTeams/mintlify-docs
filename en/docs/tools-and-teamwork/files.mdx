Files gathers what you upload and what Mira produces across all your channels, so you don't have to dig through each channel to find a résumé, JD, or report.

---

## Open Files

![The Files page listing files from across your channels, with the All, Mira generated, and My uploads tabs, search, and filters](/docs/files-open.png)

Open **Files** from the sidebar. The page lists files from across all your channels, newest first.

## Where files come from

Use the tabs at the top to filter by source:

| Tab | What it shows |
|-----|---------------|
| **All** | Every file, from every channel |
| **Mira generated** | Files Mira produced: candidate data files, reports, and other outputs |
| **My uploads** | Files you uploaded into a channel, such as a JD, a résumé, or an audio recording |

Files shared with you carry a **Shared** label on the file row.

## Find a file

When the list grows, narrow it down:

- **Search** by file name.
- **Filter** by type, channel, or date created.
- **Group** by channel or by file type, or leave it ungrouped.
- **Sort** by most recent, oldest, or file size.

Files cover the formats your channels work with: candidate data files (Search Result), documents, spreadsheets, presentations, PDFs, images, code, and plain text.

## What you can do with a file

Click a file to preview it; **Reveal in channel** and **Download** are in the row's ⋯ menu.

- **Preview** a supported file inline without leaving the page.
- **Reveal in channel**: jump to the channel the file belongs to, in context.
- **Download** a single file, or select several and **Batch download** them together.
