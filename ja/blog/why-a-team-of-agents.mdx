MiraDay を作る過程で、私たちが何度も立ち返った問い、そして数多くの優れた採用担当者と話し合ってきた問いがある。良い採用とは、実際にはどのように起きているのか、ということだ。

採用担当者が難しいポジションを引き受けるとき、仕事はたいてい要件定義から始まる。JD 単体で十分なことはめったにない。なぜ会社がその人を採用しようとしているのか、チームが何を達成しようとしているのか、Hiring Manager が各要件で本当に言いたいことは何か、ブリーフのどの部分が必須でどの部分が実は交渉可能なのか、採用成功とはそもそもどんな状態を指すのか、そしてソーシングの戦略はどうあるべきか。それらを理解する必要がある。

そこまで来て、ようやくソーシングが本当の意味で始まる。そして進めるうちに、検索の方向は変わり続ける。時にはそれが、役割そのものについての最初の理解まで変えてしまうこともある。

検索を始めた時点では、非常に具体的な理想の候補者像を思い描いていることもあるだろう。しかし市場でしばらく動いてみると、最も強い候補者たちがその像とはかなり違って見えてきたり、必須だと思っていた要件が検索の幅を狭めすぎていたことに気づいたりする。これは、埋まりにくい技術系ポジションやシニアリーダーシップの検索で特によく起きる。

そこで検索の範囲を広げ、見つけた候補者一人ひとりをより丁寧に見ていくことになる。履歴書が有望に見えた人でも、実際の経験を読んでみると合わないとわかることがある。逆に履歴書では目立たなかった人が、想定以上に良いフィットだったとわかることもある。そしてこうした発見のひとつひとつが、また検索を変えていく。

これこそが、優れた採用担当者が実際にやっていることだ。プロセスは、要件定義からソーシング、評価へと一直線に進むものではない。ある段階で発見したことが、次の段階への向き合い方を変える。そして時には、要件を考え直すために最初に引き戻されることもある。

## AI 採用はしばしば、別の前提から出発する

今日の AI 採用プロダクトの多くは、ワークフロー全体をひとつの Agent に委ねている。役割を説明すれば、その Agent が要件を解釈し、候補者を検索し、見つけたものを評価し、候補者リストを返す。

しかしこのやり方には問題があり、検索が難しくなるほどその問題は顕著になる。

役割を解釈し、検索の戦略と方向性を決める Agent は、同時に検索そのものを実行する Agent でもある。そして、最初に自分が立てた前提に照らして、見つけた候補者を評価する。もし最初の理解が少しでもずれていれば、そのプロセス全体が、非常に効率よく間違った方向へと進んでいくだけになる。

採用担当者には、通常これに気づく手立てがある。市場そのものが最初のブリーフに異を唱えてくる。同僚や Hiring Manager が検索戦略に疑問を投げかける。候補者の履歴書を丁寧に読むことで、ある要件が実はそれほど正しくなかったと明らかになることもある。こうした絶えざるシグナルが、採用担当者が時機を逃さず調整し、伝え、再調整する助けとなり、最終的に正しい人材を見つけることにつながる。

そのすべての作業がひとつの Agent の中だけで完結するとき、こうした摩擦の瞬間は簡単に失われてしまう。そして私たちは、その摩擦こそが正しい人材を見つける助けになっていると考えている。

## 私たちは、採用チームがすでにどう機能しているかに目を向けた

Agent Team というアイデアは、ここから生まれた。

私たちは「どうすればひとつの Agent にもっと多くをやらせられるか」という問いから出発したわけではない。

私たちが問うたのは、こういうことだ。もし難しいポジションを埋めるために採用チームを組むとしたら、そのチームにどう動いてほしいか。

答えは、見慣れたものだった。仕事を理にかなった形で分担する。検索が先走りすぎる前に、誰かが本当にその役割を理解する。誰かが実際に市場に出て、そこに誰がいるのかを見る。そして誰かが、良い検索結果イコール良い候補者だと決めつけず、候補者を丁寧に調べる。

肝心なのは、それぞれのメンバーが自分の担当領域を持ちながら、さまざまな形で協力し合うということだ。誰も孤立して仕事をしない。ソーシングを担当する人が戻ってきて、「想定していたような人材が見つからない。この要件を考え直したほうがいいかもしれない」と言うこともある。候補者を評価する人が、あるパターンに気づき、チーム全体が探すべき対象を変えることもある。採用は、そうやって一歩ずつ良くなっていく。

だからこそ MiraDay では、仕事のこうした異なる部分それぞれを担う Agent を構築し、それらをチームメイトとして密接につなげている。

## Mira、Atlas、Scout、そして Vera

**Mira** は Agent Team の「頭脳」だ。タスク全体を率い、それをどう分解し計画するかを決め、ひとつの検索が複数の思考様式を必要とするタイミングを判断する。

**Atlas** は要件定義を担当する。会社、市場、競合、報酬水準をリサーチし、最初の依頼を Role Brief に変換する。すなわち、その役割が実際に何を必要としているのか、事業背景、成功基準、制約、前提、そして採用の背後にある未解決の問い、それらをまとめたものだ。その Role Brief から、Ideal Candidate Profile を導き出す。検索の拠り所となる、具体的な必須条件、あれば望ましい条件、そして絶対条件から外れるものだ。ここでの狙いは、より洗練された JD を作ることではない。採用の背後にある前提を、実際に検証できるくらい明確にすることにある。

**Scout** はその理解を市場へと持ち込む。複数のデータソースを横断して、Ideal Candidate Profile に合いそうな人材を検索し、候補者プールへとまとめていく。そこで見つかった事実は、プロフィールに、そして時にはその背後にある Role Brief にさえ、異を唱えることがある。

最も強い候補者たちが、繰り返し予想外のところから出てくるなら、それ自体が有用な情報だ。答えは常に「もっと必死に探す」ことではない。時には一歩下がって役割そのものを見直すことが、正しい選択になる。

その候補者プールは、ショートリスト(shortlist)ではない。ロングリスト(longlist)に誰を残すかは人が決め、そこから先を **Vera** が引き継ぐ。Vera はそれらの候補者について深く調査を続け、判断の拠り所となるエビデンスを積み上げ、パーソナライズされたアウトリーチを準備し、初回接触と初期スクリーニングを支える。

Vera が見つけたものもまた、検索にフィードバックされる。それは意図された設計だ。

これらのチームメイトは、決まった順序で進み、出力を次々に手渡していくようには設計されていない。検索が進んでいく中で、互いに影響を与え合うように設計されている。

## 重要なのは、Agent の数ではない

3 つの Agent が 1 つの Agent より本質的に優れているとは、私たちは考えていない。

本当に興味深いのは、採用プロセスの異なる部分が互いに問い直し合うことを許されたとき、何が起きるかということだ。

市場が見せてくれるものが、Ideal Candidate Profile を作り直す。ひとりの候補者から学んだことが、検索そのものを変える。そして、たった一人を丁寧に見つめ直すことが、「正しい候補者とはどんな人か」という全体像そのものを変えることもある。

だからこそ私たちは、すべての作業をひとつのチャンネルで可視化している。ブラックボックスから最終リストだけを受け取るのではなく、チームが何を見つけているか、その思考がどこで変わったかを見ることができる。

目的は、プロセスをより複雑に見せることではない。検索の背後にある推論を、より公正で透明なものにすることだ。信頼でき、確認でき、たどることができるものに。

## チームが見つける。あなたが決める。

Agent Team は、検索の中で時間のかかる作業の多くを引き受けることができる。役割をリサーチし、市場をマッピングし、候補者を調査し、エビデンスを整理する。しかし、最終的な採用の意思決定は行わない。

決定権は、採用担当者のもとに留まる。

この区別は重要だと考えている。なぜなら「情報を見つけること」と「その情報が何を意味するかを判断すること」は、まったく別のことだからだ。AI は、自分ひとりでは到底届かないほど大きな市場を見ることを助けてくれる。そして、経験と判断力を本当に必要とする採用の部分に、より多くの時間を使わせてくれる。

それが、MiraDay がどこに位置づけられるべきかについての私たちの考え方だ。常に、採用担当者がより良い決定を下す助けとなるタスクの周りに。

## Mira がチームを呼び込むとき

ほとんどの検索は、チーム全員を必要としない。

単純な検索であれば、Mira ひとりで対応できる。検索がその前提を複数の角度から検証する必要があるほど複雑になったとき、Mira は Agent Team を呼び込む。

Agent Team がいつ介入すべきか、メンバーがどう協力し合うべきかは、まだ私たちも試行錯誤している最中だ。実際の検索をより多く見て、採用担当者が本当にどこで行き詰まるのかをより深く理解していくにつれて、このチームは変わり続けるだろう。

この探求すべての背後にある考え方は、シンプルだ。私たちは、ひとつの Agent が「何もかもひとりでこなす採用担当者」の、どんどん巨大化したバージョンになることを望んでいない。私たちが望むのは、Mira が優れた採用チームのように働くことだ。まず役割を理解し、市場から学び、見つけた人材を丁寧に見つめ、そして学んだことが次に何をすべきかを変えていく、そんな働き方だ。

なぜなら、正しい人材を見つけることは、一度も一本の直線だったことがないからだ。

**チームが見つける。あなたが決める。**
