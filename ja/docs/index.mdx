MiraDay は、プロフェッショナル職とリーダーシップ採用向けの人材インテリジェンス・プラットフォームです。AI エージェントである Mira が、Agent Team とともにあなたに適切な候補者を見つけ出します。役割を説明すれば、Mira が検索し、推論し、実際に条件に合う人材を連れてきます。どの検索にも Agent Team が投入され、各 Teammate が探索の一部を担います。膨大な検索作業はあなたの手を離れ、決断を下すのはあなたのままです。


![MiraDay のワークスペース。役割を説明し、条件に合う候補者が集まった候補者プールをレビューする](/docs/mira-overview.png)

</CardGroup>
