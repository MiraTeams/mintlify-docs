最適な候補者を見つけられたら、それは一つの成果です。そのやり方を残しておけば何度でも再現できます。それが Skill です。ソーシングブリーフのフォーマット、評価基準、レポート構成など、繰り返し使うワークフローを保存しておけば、毎回同じ要件をゼロから説明する代わりに、どのチャンネルでも再利用できます。

---

## Skills とは

Skill は、繰り返し発生する仕事を Mira にどう処理してほしいかをまとめた保存済みの指示セットです。ヒアリング用の質問項目、評価基準、クライアントにそのまま出せるレポートのフォーマット、さらには実行するツールとその順序まで含められます。Mira はそれを単発のプロンプトとしてではなく、エンドツーエンドで仕事として実行します。Skill には 2 種類あります:

- **公式 Skill**: Mira チームが作成・メンテナンスし、**公式** タブに一覧表示されます。詳しくは後述します。
- **パーソナル Skill**: 自分で作成したもので、自分のアカウントからのみ見えます。

Skill をエクスポートしてファイルを共有すれば、チーム全体が同じやり方で仕事を進められます。

## 公式 Skill

公式 Skill は **公式** タブに表示されます。ほかの Skill と同じように呼び出せるほか、リクエストが合致すると Mira が自動で適用します（[Skill を呼び出す](#skill-を呼び出す) を参照）。

### skill-creator

何度も繰り返し使うことになる公式 Skill が **skill-creator** です。会話を通じて自分の Skill を作成・編集でき、ファイルを書く必要はありません。

- **できること:** ワークフローを普通の言葉で説明すると、skill-creator がそれを Skill に変換し、指示文を代わりに書き起こしてくれます。
- **使い方:** Skills の設定で **新規スキル** をクリックし、次に **チャットで作成** を選びます（Mira が skill-creator を実行するチャンネルを開きます）。あるいは、どのチャンネルでも **/skill-creator** と入力します。詳しい流れは [Skill を作成する](#skill-を作成する) を参照してください。自分の Skill をあとから修正するには、その Skill を開いて **編集** をクリックします。
- **使いどころ:** 繰り返し使うプロセス（ヒアリング用のチェックリスト、評価基準、クライアントにそのまま出せるレポートのフォーマットなど）があり、それを `SKILL.md` を手で編集せずに再利用可能な Skill として保存したいときです。

## Skill を呼び出す

1. チャンネル入力欄のツールバーにある **スキル** ボタンをクリックするか、**/** を入力します。利用できる Skill の一覧（ピッカー）が表示され、**すべてのスキルを表示** から Skills の設定に移動できます。
2. Skill を選ぶか、そのまま入力を続けて名前で絞り込みます。
3. 今回の実行内容を具体的に書いて送信します。メッセージには Skill 名がチップとして表示され、Mira はその Skill の指示に従ってチャンネルを進めます。

![チャンネル入力欄にスラッシュを入力すると開くスキルピッカー。利用できる Skill が一覧表示されている](/docs/skills-picker.png)

Mira が関連する Skill を自動的に適用することもあります。各 Skill には短い説明が付いており、リクエストがそれに合致すると、Mira は自動でその Skill を使います。

## Skill を作成する

Skills の設定を開き（**設定**、次に **スキル**）、**新規スキル** をクリックします。作成方法は 2 つあります。

![Skills 設定の「新規スキル」メニュー。「チャットで作成」と「ファイルをインポート」が表示されている](/docs/create-skill.png)

**チャットで作成**。Mira が公式の **skill-creator** Skill 付きで新しいチャンネルを開き、あなたが説明したワークフローを会話を通じて Skill に仕上げます。ドラフトが完成すると、Mira はそれをカードとして会話に届けます。プレビューを確認し、**マイスキルに追加** をクリックして保存してください。

**ファイルをインポート**。`.md`、`.skill`、または `.zip` ファイル（最大 10 MB）をドロップします。単体の `.md` ファイルの場合、ファイル名は `SKILL.md` にする必要があります。Mira が `SKILL.md` の frontmatter を解析して Skill を追加し、名前・トリガー・ソース・ファイルを表示する詳細ページを開きます。Skill パッケージの構成は次のとおりです:

- `SKILL.md`（必須）: frontmatter に Skill ID（slug）と短い説明（最大 1024 文字。Mira はこれをもとに Skill を自動適用するかどうかを判断します）を記載し、その後に markdown 形式の指示（最大 100 KB）を書きます。
- 補助ファイル用の `scripts/`、`references/`、`assets/` フォルダ（任意）。

名前が公式 Skill と重複する場合は、`SKILL.md` の frontmatter で名前を変更し、もう一度アップロードしてください。自分の Skill と重複する場合は、置き換えるかどうかを Mira が確認します。上書きするには **置き換えて保存** をクリックします。

## Skill の詳細ページ

Skills の設定で任意の Skill を開くと、その詳細ページが表示されます。説明、ソース、トリガー方法（**自動ルーティング** など）、オン / オフのトグルを確認できます。パーソナル Skill では、さらに作成日時または最終編集日時、作成方法（アップロードまたは会話）、バージョン、Skill のファイル一覧（行をタップすると読み取り専用のプレビューが開きます）も表示されます。パーソナル Skill では、次の操作もできます:

- **編集**: 変更を **skill-creator** に任せます。設定が閉じ、Mira はその Skill を作成したチャンネルで続きを引き受けます。そのチャンネルがもう存在しない場合や、Skill をファイルからインポートした場合は新しいチャンネルを開き、変更を反映してくれます。
- **.skill をエクスポート**（⋯ メニュー内）: Skill を `.skill` ファイルとしてダウンロードします。
- **削除**（⋯ メニュー内）: Skill を完全に削除します。`SKILL.md` と `scripts/`、`references/`、`assets/` 配下のすべてが削除され、元に戻せません。

## Skill を管理する

Skills の設定には、すべての Skill が **すべて**、**公式**、**個人** の 3 つのタブに一覧表示されます。

![公式 Skill と個人 Skill を一覧表示する Skills 設定ページ。各 Skill にオン / オフのトグルが付いている](/docs/skills-settings.png)

各 Skill はトグルで**有効 / 無効**を切り替えられます。無効化した Skill は使われません。編集・エクスポート・削除は Skill の詳細ページで行います。

## FAQ

### 利用できる公式 Skill は?

**公式** タブには、Mira チームが提供し、あなたのアカウントで有効化している Skill が一覧表示されます。会話を通じて自分の Skill の作成・編集を手伝う **skill-creator** もその一つです。新しい公式 Skill は、Mira チームのリリースに合わせてここに追加されます。

### Skill をチームメンバーと共有できますか?

組み込みの共有機能はまだありません。Skill を `.skill` ファイルとしてエクスポートすれば、誰でも自分の Skills 設定の **新規スキル** から **ファイルをインポート** でインポートできます。こうして、パーソナル Skill はチーム全体に受け継がれ、活用されていきます。
