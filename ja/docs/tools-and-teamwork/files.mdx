Files は、すべてのチャンネルであなたがアップロードしたものと Mira が生成したものを一か所に集めます。履歴書や JD、レポートを探すために、チャンネルを一つずつ掘り返す必要はありません。

---

## Files を開く

![チャンネルをまたいだファイルを一覧表示し、すべて、Mira 作成、私がアップロードの各タブ、検索、フィルタを備えた Files ページ](/docs/files-open.png)

サイドバーから **Files** を開きます。ページにはすべてのチャンネルのファイルが新しい順に一覧表示されます。

## ファイルの出所

ページ上部のタブでソースを絞り込めます。

| タブ | 表示内容 |
|------|----------|
| **すべて** | すべてのチャンネルのすべてのファイル |
| **Mira 作成** | Mira が生成したファイル。候補者データファイル、レポート、その他の出力 |
| **私がアップロード** | チャンネルにアップロードしたファイル。JD、履歴書、音声録音など |

あなたと共有されたファイルには、ファイルの行に **共有** ラベルが付きます。

## ファイルを探す

ファイルが増えてきたら、以下の方法で絞り込めます。

- ファイル名で**検索**する。
- 種類、チャンネル、作成日で**フィルタ**する。
- チャンネル別またはファイル種類別に**グループ化**する。グループ化せずに表示することもできます。
- 最新順、古い順、ファイルサイズ順で**並び替える**。

Files は、チャンネルが扱うファイル形式に対応しています。候補者データファイル（検索結果）、ドキュメント、スプレッドシート、プレゼンテーション、PDF、画像、コード、プレーンテキストです。

## ファイルでできること

ファイルをクリックするとプレビューできます。**チャンネル内で表示** と **ダウンロード** は、各行の ⋯ メニューにあります。

- 対応しているファイルは、ページを離れずにインラインで**プレビュー**できます。
- **チャンネル内で表示**: そのファイルが属するチャンネルに、コンテキスト付きで直接ジャンプします。
- ファイルを 1 つ**ダウンロード**する、または複数を選択して**まとめてダウンロード**します。
