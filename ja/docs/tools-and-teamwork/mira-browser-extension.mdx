Mira ブラウザ拡張機能は、Mira があなた自身の Chrome ブラウザを操作して、サインインが必要なサイトなど、ビルトインソースにない情報にアクセスできるようにします。あなた自身のログインを使い、通常は専用タブで、または明示的に指定した既存のページで動作します。Mira の動作を見守り、いつでも自分で操作を引き継げます。

---

## 用途

- **指定したサイトをブラウズする。** ブラウズしてほしい特定のウェブサイトを Mira に伝えると、代わりにブラウズし、見つけた内容を持ち帰ります。
- **サインインの先にいる候補者にアクセスする。** ログイン済みの採用サイトを開くと、Mira がプロフィールを読み取り、適格な候補者をマッチングのために持ち帰ります。
- **企業やチームを調査する。** 企業のリーダーシップ、最近の資金調達、特定チームのメンバーについて尋ねると、Mira がライブのウェブから収集します。
- **サインイン済みの他の SaaS ツールにアクセスする。** Mira はあなた自身のブラウザセッションを通じて動作するため、すでにログインしている ATS、CRM、その他のアカウントにアクセスできます。

## インストールと接続

1. [Chrome Web Store](https://chromewebstore.google.com/detail/mira-chrome-extension/eehnmnpglnfhkkcepfdlnnolobnjfcoh) で **Mira ブラウザ拡張機能** を見つけ、**Chrome に追加** をクリックします。**設定** の **ブラウザ拡張機能** にある **拡張機能をインストール** ボタンからインストールすることもできます（デスクトップのみ）。
2. チャンネル入力欄に小さな拡張機能アイコンが表示されます（デスクトップのみ。モバイルでは表示されません）。Mira が拡張機能を検出している間、ボタンは無効になります。拡張機能が未インストールの場合は、クリックするとインストール手順が開きます。インストール済みで未接続の場合は、クリックすると状況に応じて **接続**、**承認**、**更新**、**更新する** のいずれかが表示されます。接続後はトグルとして機能します（下記参照）。
3. Mira が初めてあなたのブラウザを必要とするとき、**Mira がブラウザの制御を要求しています** というカードが表示されます。Mira はログイン済みのサイトを利用し、通常はチャンネル専用のタブで操作します。明示的に依頼すれば、既存のタブで作業を続けることもできます（下記参照）。すべての操作は記録されて確認でき、支払いや削除などの重要な操作は事前に確認を求めます。**認可する** をクリックすると、その後は記憶されるため、チャンネルごとに設定する必要はありません。

チャンネルが拡張機能を必要とするときに準備ができていない場合、Mira はインストール、承認、または再接続の手順を案内するカードを表示し、接続が完了すると自動的にチャンネルを再開します。

拡張機能が Mira の必要とするバージョンより古い場合、更新するまでブラウジングがブロックされます。Mira は **更新が必要** と表示された **Mira ブラウザ拡張機能を更新** というカードを表示し、スキップするオプションはありません。拡張機能の比較的新しいバージョンでは、**今すぐ更新** をクリックすると、ページを離れることなくワンクリックで更新がインストールされます。それ以外の場合や、ワンクリック更新がうまくいかない場合は、手動で更新します：

1. `chrome://extensions/` を開き、右上の **デベロッパー モード** をオンにして、左上の **更新** をクリックします。
2. それでも更新できない場合は、Mira 拡張機能を見つけて **削除** をクリックし、カード上の **ストアを開く** ボタンを使って **Chrome に追加** をクリックし、再インストールします。

更新が完了すると、Mira はチャンネルの作業を再開します。

## チャンネルでの使い方

![ブラウザの接続済みステータスカード、Mira のナビゲートステップ、チャンネル入力欄の拡張機能ボタンが表示された、チャンネル内で動作する拡張機能](/docs/channel-browser.png)

チャンネルでやってほしいことを入力するだけです。Mira は必要なものを得るのにブラウジングが最適な方法であるかを自ら判断し、あなた自身のブラウザの専用タブで作業します。拡張機能が接続されているとき、そのボタンは現在のターンに対する任意のトグルとしても機能します。オフのままにすれば Mira が判断し、オンにすれば今回は Mira にブラウザを優先させます。

拡張機能のバージョンが **0.4.18 以降**なら、すでに開いているページで作業を続けるよう Mira に依頼できます。そのタブがタスクの作業用タブとなり、絞り込み条件やページの状態が保たれます。どのページか不明な場合は会話の中で確認し、追加の認可カードやブラウザのダイアログは表示されません。

Mira が、ユーザー名とパスワードでのサインイン、CAPTCHA、二要素認証の入力など、あなたの操作を必要とするステップに達すると、**一時停止して 続行 ボタンを表示し**、待機します。いつでも自分でタブを引き継ぐこともでき、Mira は待機して、あなたが **続行** をクリックすると再開します。**ブラウザセッションを表示** を開いて作業の様子を見守ることができ、支払い、削除、送信などの重要な操作は常に事前にあなたの確認を求めます。

## チームと連携

Agent Team の Teammate も拡張機能を使ってブラウズできます。ブラウザアクセスを最初に一度だけ付与すれば、Mira がそのチャンネルのために立ち上げる Teammate が、同じ方法であなたのブラウザで拡張機能を使えます。

## プラットフォームコンプライアンス

多くの採用プラットフォームには、自動アクセスを制限する利用規約があります。拡張機能は合理的な使用パターンの範囲内で動作するよう作られていますが、サードパーティプラットフォームの利用規約への準拠はユーザーの責任です。一括スクレイピングではなく、ターゲットを絞った特定の検索に使用し、自身のプラットフォームアカウントを良好な状態に保つことをおすすめします。

## プライバシーとセキュリティ

- Mira はあなた自身のブラウザとログインを使い、通常はチャンネル専用のタブで作業します。既存のページを明示的に指定すると、そのタブがタスクの作業用タブとなり、関係のないタブは操作対象に含まれません。
- Mira はパスワードや Cookie を保存せず、すでにサインインしているセッションを通じて動作します。
- 重要な操作は事前にあなたの確認を求め、すべての操作は記録され、閲覧できます。
- 拡張機能は現在 Chrome のみに対応しています。
- すべてのデータの取り扱いは MiraDay の[プライバシーポリシー](/ja/docs/match-quality-and-trust/privacy-policy)に準拠します。
