プールの各候補者には、あなたの検索に合わせて作られたプロフィールが付いています。Mira は複数の公開ソースで見つかった同一人物を 1 人の候補者に統合し、情報が集まるにつれてプロフィールを充実させます。非公開の連絡先レコードは、同一人物であっても公開ソースの候補者とは別に扱われます。ここでは、その読み方と適合度の判断方法を説明します。

## 候補者カードの内容

![氏名、勤務地、現在の役職、最終学歴、そして高適合の適合ラベル付き評価基準を表示する候補者カード](/docs/candidates-mira-scores-each.png)

結果パネルでは、各候補者がカードとして表示され、次の情報が含まれます。

- **ヘッダー**: 氏名と、今回の検索で使われたソース上の本人プロフィールへのクリック可能なソースリンク（LinkedIn、GitHub、Hugging Face、X (Twitter) など）。その人物が見つかった採用プラットフォームへのリンクも含まれます。GitHub や Hugging Face などのソースで検索するよう Mira に頼めば、それらのプロフィールへのリンクがカードに表示されます。
- **現在の役職**（役職名・会社名・期間）。その下の行に **勤務地・最終学歴**（学位、教育機関、分野、年数）。
- **評価基準**のプレビュー。全体の適合ラベルとともに最初の 5 つの要件が表示され、**もっと見る** で残りを展開できます。

カードをクリックすると、候補者の **プロフィール** 全体が開きます。ここにはメールと電話の行、**自己紹介**のサマリー、要件ごとの完全な評価、すべての職歴と学歴、スキルと言語が加わり、データがある場合は GitHub と Hugging Face での活動、論文、受賞歴、資格・認定、コースも表示されます。さらに **その他** セクションには、ウェブやニュースでの言及（記事のタイトル、公開日、関連する一文）がまとまっています。上部の矢印で前後の候補者に移動できます。

結果パネルは **カード表示** で開きます。パネル上部のトグルで **リスト表示** に切り替えると、コンパクトな表（候補者と適合ラベル、リンク、メール、電話、所在地、役職、会社、学校、学位、専攻）で確認でき、多数の候補者を一度にざっと見渡すのに便利です。

## 適合ラベル

各候補者には、あなたの検索にどれだけ合致するかを一目で示す色分けされた適合ラベルが付いています。

- **高適合**（緑）: あなたの要件に対して最も強く合致する候補者。
- **部分適合**（黄）: 一見の価値がある部分的な合致。
- **低適合**（グレー）: 要件に対して最も離れている、合致度の弱い候補者。

候補者は適合度順に並ぶため、最も強く合致する候補者が上位に表示されます。

## 評価基準

**評価基準** セクションには、あなたの必須要件が一つずつ並びます。各要件について、Mira は候補者がそれを満たしているか（チェック）、根拠が薄いか（ダッシュ）、あるいは不足しているか（バツ）を、その裏付けとなる根拠とともに示します。これは一般的な経歴紹介ではなく、あなたの具体的な検索に合わせて書かれています。

## 候補者の評価方法

ラベルと評価基準はすばやく把握するためのものです。判断を下す前に、より深く見てみましょう。

- **タイトルの先を見る。** 同じタイトルでも企業によって意味が異なります。10 人のスタートアップの「シニアエンジニア」は、大企業の同じタイトルとはまったく異なる役割です。企業コンテキストを使って、実際の職務範囲を読み取りましょう。
- **キャリアの軌跡を確認する。** 昇進のスピードと、各役職での企業タイプは多くを物語ります。大企業からスタートアップ、その後成長ステージへと移った人は、一つの環境に留まった人とは異なるプロフィールを持っています。
- **評価基準を出発点として使う。** 評価基準はあなたの検索に最も関連性の高い点をハイライトします。それだけでは捉えきれないニュアンスは、完全な職歴と学歴を読んで確かめましょう。

## 候補者への連絡

各カードにはメールと電話の行があります。カード上、リスト表示、フルプロフィールのいずれでも、**メールを取得** または **電話を取得** をクリックすると表示できます。電話番号の取得中は、その行に **電話番号を取得中…** と表示されます。複数人をまとめて表示するには、カードのアバターにカーソルを合わせてチェックボックスをオンにし（または **すべて選択** を使い）、パネル下部のバーで **メールを取得** または **電話番号を取得** をクリックします。1 回につき最大 50 人まで処理できます。表示にはクレジットを消費し、電話はメールよりコストがかかります。

自分の連絡先ライブラリにある既存のメールアドレスや電話番号は、そのまま表示される場合があります。フルプロフィールの **メールを補完** と **電話を補完** では、再検索して追加の情報を既存の値に統合できます。Credits を消費する場合があり、再試行まで一定の間隔を置く必要があります。新しい情報が見つかるとは限りません。

## 候補者を保存する

この検索を超えてその人を残しておくには、カード右上の **連絡先に追加** アイコン（またはフルプロフィール内のボタン）をクリックします。複数人を保存するには、チェックボックスをオンにしてから、下部のバーで **連絡先に追加** をクリックします。保存した人は、ワークスペースレベルのリストである [連絡先](/ja/docs/tools-and-teamwork/contacts) に追加され、そこで情報を補強したり、常に最新の状態に保ったりできます。

結果パネルが狭い場合、下部のバーの **電話番号を取得** と **連絡先に追加** は **その他** に入ることがあります。**一括ダウンロード** はそのまま表示されます。
